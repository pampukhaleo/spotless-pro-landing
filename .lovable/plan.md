# Отмена незавершённого слияния Git

1. Закрыть окно Commit в WebStorm и выполнить в Git Bash:
   ```bash
   git merge --abort
   ```
2. Проверить результат:
   ```bash
   git status
   ```
   Локальный коммит `32ff786` должен сохраниться, а сообщение о незавершённом слиянии — исчезнуть.
3. Чтобы позже синхронизировать изменения без merge-коммита, выполнить:
   ```bash
   git pull --rebase origin main
   git push origin main
   ```
4. Если во время `pull --rebase` появится конфликт, остановиться и показать вывод терминала, не выбирая версии файлов наугад.

## Важно

Не нажимать **Amend last commit**: эта опция изменяет предыдущий коммит и недоступна во время слияния.
