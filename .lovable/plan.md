# Улучшение видимости hiring-ссылки

## Что делаем

Сделать плашку «We're Hiring — Join Our Team» заметнее и выровнять по центру на десктопе.

## Изменения

1. **Размер на десктопе**: увеличить padding и текст — `md:px-6 md:py-3 md:text-base`.
2. **Центрирование**: убрать прижатие влево на десктопе, оставить `justify-center` для всех размеров.
3. **Тень/вес**: усилить тень (`shadow-md` по умолчанию, `hover:shadow-lg`) и при hover лёгкое увеличение (`hover:scale-105`) без анимационных зависимостей — только Tailwind transition.
4. **Мобильная версия**: оставить текущий размер или чуть увеличить до `text-sm`/`py-2.5`.
5. **Контраст**: фон остаётся `bg-background/90`, текст `text-foreground`, иконка `text-secondary` — без новых цветов.
