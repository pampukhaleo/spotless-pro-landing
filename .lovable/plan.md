# Безопасная отмена заблокированного слияния

1. Закрыть WebStorm или остановить запущенные npm/bun-процессы, чтобы `bun.lockb` больше не изменялся.
2. В Git Bash из папки проекта сохранить резервную копию проблемного файла вне репозитория:
   ```bash
   cp bun.lockb ../bun.lockb.before-merge-abort
   ```
3. Принудительно отменить состояние слияния и вернуться к локальному коммиту `32ff786`:
   ```bash
   git reset --hard HEAD
   ```
4. Проверить состояние:
   ```bash
   git status
   git log --oneline -3
   ```
   Сообщение `still merging` должно исчезнуть, а локальная и удалённая ветки пока останутся разошедшимися на 1 и 3 коммита.
5. Не выполнять `pull` или `push` до проверки результата. Прислать вывод двух команд из шага 4, чтобы выбрать безопасный способ синхронизации.

## Что сохранится

Ваш уже созданный коммит `32ff786` останется в истории. Копия `bun.lockb` будет лежать уровнем выше папки проекта. Незавершённые изменения, полученные во время merge, будут удалены из рабочей папки.
