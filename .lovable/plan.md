# Привести локальную ветку к состоянию GitHub

Текущее состояние: рабочая папка чистая, локальная ветка отличается от GitHub на один ваш коммит `32ff786`, а на GitHub есть три новых коммита.

1. Скачать актуальные ссылки на ветки без изменения файлов:
   ```bash
   git fetch origin
   ```
2. Необратимо удалить локальный коммит `32ff786` и сделать локальную папку полностью равной `origin/main`:
   ```bash
   git reset --hard origin/main
   ```
3. Проверить результат:
   ```bash
   git status
   git log --oneline -3
   ```
   Должно отображаться `Your branch is up to date with 'origin/main'` и `nothing to commit, working tree clean`.

## Что произойдёт

Ваш локальный коммит `32ff786` будет удалён навсегда; на GitHub он не отправлялся, поэтому в удалённом репозитории ничего дополнительно меняться не будет. Изменения из GitHub окажутся на компьютере.
